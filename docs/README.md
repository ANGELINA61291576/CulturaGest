# Documentación de Arquitectura - CulturaGest

## Estructura de la Base de Datos

### Tablas:
- Participantes (alumnos)
- Profesores (docentes)
- Talleres
- Inscripciones
- Asistencia
- Consultas
- Usuarios

## Tecnologías Utilizadas

- **Backend:** Node.js, Express
- **Base de Datos:** SQLite
- **Autenticación:** JWT
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
